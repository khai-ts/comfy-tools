# Research

Notes from research done while working on the brands: competitors, trends, audiences, platforms, festivals,
regulations, and anything else that informs the content. The agent adds to this folder as it works.

## How to add a note

One file per topic: `research/<yyyy-mm-dd>-<topic>.md`, for example `2026-10-12-malaysia-magnesium-competitors.md`.
Use this shape:

```markdown
# <Topic>

- Date researched: <yyyy-mm-dd>
- Brand: naelnewk | innoasia | both
- Asked by: <person, or "agent initiative">

## Key findings
- <finding> ([source](https://...))

## What it means for us
- <implication for the brand, content ideas, things to try or avoid>

## Sources
- <title>: <url> (accessed <date>)
```

- Summarise in your own words and link to sources. Don't paste other brands' copy or save their images here.
- Mark anything uncertain or time-sensitive (prices, trends, follower counts) as such: it goes stale.
- When a finding changes how we do things, also update `brand/<slug>/BRAND.md` or `brand/IDEAS.md`, and log
  it in `brand/CHANGELOG.md`.
